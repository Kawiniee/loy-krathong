# คืนวันเพ็ญ · ลอยกระทงกันเถอะ!

เกมงานลอยกระทงภาษาไทยสำหรับสองคน แต่งกระทงจากวัสดุที่วางได้อิสระ แล้วลอยกระทงที่สร้างจริงพร้อมกันใต้แสงจันทร์

## เปิดเล่นในเครื่อง

ใช้ Node.js 22.12 ขึ้นไป

```sh
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดง แล้วเลือก **เล่นสองคนบนเครื่องเดียว** หรือ **เริ่มเล่นสองคน** หากยังไม่ได้ตั้งค่าออนไลน์ ใส่ชื่อทั้งคู่และใช้ปุ่ม **สลับผู้เล่น** เพื่อแต่งคนละใบและกดพร้อมลอย ร้านแต่งกระทงจะบันทึกงานทุกครั้งที่แก้ไข

## เปิดห้องออนไลน์และ Deploy บน Vercel

1. สร้างโปรเจกต์ Supabase แล้วเปิด **Allow anonymous sign-ins** ในหน้า Authentication
2. เปิด SQL Editor แล้วรัน [migration ตั้งค่าห้อง](supabase/migrations/202611240001_festival.sql) ตามด้วย [migration คลังวัสดุ](supabase/migrations/202611240002_material_catalog.sql) สำหรับโปรเจกต์ที่เล่นออนไลน์ได้อยู่แล้ว ให้รันเฉพาะ migration คลังวัสดุก่อน Deploy เวอร์ชันใหม่
3. สำหรับการทดสอบในเครื่อง คัดลอก [.env.example](.env.example) เป็น `.env.local` ใส่ Project URL และ publishable key จาก Supabase แล้วเปิดเซิร์ฟเวอร์ Vite ใหม่
4. นำ repo ที่มีโค้ดชุดนี้เข้า Vercel เป็นโปรเจกต์ **Vite** จากนั้นตั้ง `VITE_SUPABASE_URL` และ `VITE_SUPABASE_PUBLISHABLE_KEY` ใน Environment Variables แล้ว Deploy ค่าทั้งสองถูกฝังในเว็บเมื่อ build จึงใช้ publishable key เท่านั้น
5. เปิด URL ที่ Deploy แล้วจากสองเบราว์เซอร์หรือสองอุปกรณ์ คนแรกสร้างห้องและคัดลอกลิงก์ คนที่สองเปิดลิงก์ ตั้งชื่อ แล้วเข้าห้อง ทดสอบว่าวัสดุที่เพิ่มในโหมด **ช่วยกันแต่ง** ปรากฏทั้งสองฝั่งและทั้งคู่เห็นการนับถอยหลังเมื่อกดพร้อมลอย

เอกสารอ้างอิง [Supabase Anonymous Sign-Ins](https://supabase.com/docs/guides/auth/auth-anonymous) · [Supabase Realtime](https://supabase.com/docs/guides/realtime/subscribing-to-database-changes) · [Vite on Vercel](https://vercel.com/docs/frameworks/frontend/vite)

## กิจกรรม

- **ร้านแต่งกระทง** — ลากวัสดุจากคลังหรือแตะเพื่อเพิ่ม จากนั้นลากชิ้นงานให้เข้าที่ หมุน ย่อ ขยาย ทำสำเนา จัดชั้น จัดแนวตามตาราง หรือวางเป็นวง 4, 6, 8 หรือ 12 ตำแหน่ง แต่งของตัวเอง ช่วยกันแต่งใบเดียว หรือแต่งเป็นของขวัญ
- **คลังวัสดุ** — มี 53 ชิ้นใน 8 หมวด ลองจับคู่ฐานจักสานกับพวงมาลัย ทำเกาะปะการังใส่ปลาคาร์ป หรือแต่งเกาะดวงดาวด้วยผลึกอเมทิสต์กับไข่มังกร
- **ซุ้มแข่งแต่งกระทง** — เลือกเวลา 60, 120 หรือ 180 วินาที รับโจทย์ร่วมกัน ดูงานหลังหมดเวลา และส่งความรู้สึกให้เพื่อน
- **ท่าน้ำลอยกระทง** — เลือกผลงาน จุดเทียนและธูป เลือกตำแหน่งปล่อย และกดพร้อมทั้งคู่ คำอธิษฐานเก็บเฉพาะในแท็บบนเครื่องของผู้เล่น
- **จุดถ่ายภาพ** — ปรับกล้อง เลือกกรอบ เปิดหรือปิดชื่อ แล้วดาวน์โหลด PNG ขนาด 1920 × 870 พร้อมวันที่ 24 พฤศจิกายน 2569

ห้องออนไลน์มีสองที่นั่ง สิทธิ์เข้าห้องผูกกับบัญชีชั่วคราวในเบราว์เซอร์เดิม การรีเฟรชใช้ที่นั่งเดิม การล้างข้อมูลเว็บหรือเปลี่ยนเบราว์เซอร์จะใช้บัญชีชั่วคราวใหม่

## ผลทดสอบ

| การตรวจ | ผล |
| --- | --- |
| TypeScript, ESLint และ production build | ผ่าน ทั้ง build ค่าเริ่มต้นและ build ที่เปิดโหมดออนไลน์ด้วยค่าทดสอบ |
| PostgreSQL ผ่าน PGlite | ผ่าน 5 กรณี ครอบคลุม RLS, ห้องเต็ม, การแก้ไขพร้อมกัน, ของขวัญ, พิธีลอย และการแข่งจับเวลา |
| Chrome ผ่าน Playwright | ผ่าน 4 กรณี ครอบคลุมการลากและแก้ชิ้นงาน, รีเฟรช, ห้องจากสองเซสชัน, นับถอยหลังพร้อมกัน, PNG, มือถือจำลอง และการแข่ง |

ตรวจภาพ PNG ที่ Chrome ดาวน์โหลดจริงแล้ว ภาพมีวัสดุของกระทงทั้งสองใบพร้อมกรอบและวันที่

```sh
npm run typecheck
npm run lint
npm run test:db
npm run test:browser
npm run build
```

Playwright ใช้ Chrome ที่ติดตั้งในเครื่อง การทดสอบสองเซสชันใช้ PostgreSQL ผ่าน PGlite และ HTTP fixture ในเครื่อง โดยรัน migration และกฎสิทธิ์จริง การเชื่อมต่อ Supabase Auth และ Realtime ของโปรเจกต์ที่โฮสต์ต้องทดสอบเพิ่มหลังตั้งค่า

ทดสอบหลัง Deploy จาก PowerShell โดยตั้ง `$env:LK_PRODUCTION_URL` เป็น URL Production แล้วรัน `npm run test:browser` ชุดทดสอบจะใช้สองเบราว์เซอร์เซสชันของ Chrome ตรวจลิงก์เชิญ การแก้ไขร่วมกัน เหตุการณ์ WebSocket ของ Realtime และพิธีลอยบนเว็บจริง

## ข้อจำกัดของ MVP

- กระทงหนึ่งใบรองรับสูงสุด 300 ชิ้น วัสดุพื้นฐานทุกชนิดวางซ้ำได้โดยไม่เสียแต้ม
- มินิเกมปาลูกโป่ง ตกปลา และ Festival Tokens ยังไม่ได้ทำ เสียงน้ำ ดนตรี และเสียงประกอบสังเคราะห์ในเบราว์เซอร์ เปิดได้จากเมนูเสียง
